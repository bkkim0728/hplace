# H.PLACE 공식 웹사이트

외국인 고객을 위한 에이치플레이스(H.PLACE) 공식 사이트입니다.
서울·분당 16개 지점을 한 페이지에서 안내하고, 한국어와 영어를 버튼으로 전환할 수 있습니다.
프로그램 설치도, 빌드도 필요 없습니다. `index.html` 파일 하나와 `assets` 폴더가 전부입니다.

---

## 1. 폴더 구조

```
hplace-site/
├── index.html              ← 사이트 전체 (여기 하나만 고치면 됩니다)
├── README.md               ← 지금 읽고 계신 파일
└── assets/
    ├── fonts/              ← Paperlogy 글꼴 3종 (지우지 마세요)
    └── photos/             ← 사진 (보내주신 사진이 흑백으로 들어 있습니다)
        ├── h-mark.png            로고 H (히어로·슬로건에 사용)
        ├── consult.jpg           상담 장면 (갤러리)
        ├── consult-wide.jpg      상담 장면 가로컷 (상담 방법 섹션)
        ├── stylist.jpg           디자이너 (갤러리)
        ├── stylist-portrait.jpg  디자이너 세로컷 (브랜드 소개 섹션)
        ├── result.jpg            시술 결과 (갤러리)
        └── interior.jpg          살롱 내부 (갤러리)
```

## 2. 내용 바꾸기 — 딱 한 군데만 고칩니다

`index.html` 파일을 메모장이나 VS Code로 엽니다.
아래쪽으로 내리다 보면 이런 표시가 나옵니다.

```
▼▼▼  여기만 고치시면 됩니다  ▼▼▼
```

그 아래 `const SALON = { ... }` 부분의 값만 바꾸세요.

| 항목 | 무엇을 넣나요 | 지금 상태 |
|---|---|---|
| `instagram` | 인스타 아이디를 `@` 없이 | ✅ `h.place_official` |
| `whatsapp` | 국가번호부터 숫자만. 010-1234-5678 → `"821012345678"` | ⚠️ **가짜 번호. 꼭 바꾸세요** |
| `trust` | 지점 수, 디자이너 수, 재방문율, 업력 | ✅ 16 / 160+ / 90% / 8년 |
| `branches` | 지점 목록 (이름·지역·주소·전화·시간) | ⚠️ **5개만 채워짐. 11개 추가 필요** |
| `common` | 전 지점 공통 안내 (시간·언어·결제·예약) | ✅ |
| `menu` | 시술 이름과 시작가 | ⚠️ **대부분 `₩00,000~`. 공식가로 교체 필요** |
| `gallery` | 사진 파일 이름 | ✅ 보내주신 사진 4장 적용 |
| `faq` | 자주 묻는 질문과 답 | ✅ |

### 지점 추가하는 법

`branches: [ ... ]` 안에서 지점 하나는 이렇게 생겼습니다.

```js
{ area:"SEOCHO",  name:{ko:"서초교대점", en:"Seocho Gyodae"},
  addr:{ko:"서울 서초구 서초동 1574-10 2층", en:"2F, 1574-10 Seocho-dong, Seocho-gu, Seoul"},
  tel:"0507-2006-3221", hours:"10:30 – 20:00" },
```

이 다섯 줄을 통째로 복사해서 아래에 붙이고 내용만 바꾸면 지점이 하나 늘어납니다.
**마지막 지점 뒤에는 쉼표를 붙이지 마세요.** 지도 버튼은 지점 이름으로 네이버지도를
자동 검색하므로 따로 주소를 넣지 않아도 됩니다.

`area` 는 카드 위에 작게 뜨는 지역 표시입니다. `SEOCHO`, `SONGPA`, `BUNDANG` 처럼
영문 대문자로 넣으면 외국인 손님이 알아보기 쉽습니다.

**주의할 점 세 가지**

1. 따옴표 `" "` 안의 글자만 바꾸세요. 쉼표 `,` 와 중괄호 `{ }` 는 건드리지 마세요.
2. 글 안에 큰따옴표 `"` 를 쓰지 마세요. 대신 작은따옴표 `'` 를 쓰시면 됩니다.
3. 목록의 **마지막 항목 뒤에는 쉼표를 붙이지 않습니다.** 화면이 하얗게 나오면 대부분 이 문제입니다.

`ko:` 는 한국어, `en:` 은 영어입니다. 둘 다 채워야 언어 전환이 제대로 됩니다.

### 브랜드 소개 글 고치기

브랜드 소개(About) 섹션의 글은 `SALON` 안이 아니라 HTML 본문에 있습니다.
`index.html` 에서 `<!-- 브랜드 소개 -->` 를 찾으시면 됩니다.

문장은 `data-ko="한국어 문장"` 과 `data-en="English sentence"` 두 벌로 되어 있습니다.
**두 곳을 모두 고쳐야** 언어 전환이 어긋나지 않습니다. 태그 사이의 글자는 처음 화면에
보이는 한국어라서 `data-ko` 와 같게 맞춰 두면 좋습니다.

여기에 쓰인 사실은 공개된 자료에서 확인한 내용입니다.
함성소리 미용그룹 소속, 8년, 16개 지점, 디자이너 160여 명, 재방문율 90%,
브랜드 가치 &lsquo;소통과 경청&rsquo;, 서초아크로비스타점 디자이너 20명.
**숫자가 최신이 아니면 꼭 고쳐주세요.** 특히 재방문율은 공개 자료 기준이라 내부 수치와
다를 수 있습니다.

## 3. 사진 넣기

보내주신 사진 5장은 이미 흑백으로 변환해 넣어 두었습니다.
사이트 톤에 맞춰 채도를 없애고 어둡게 낮춘 뒤, 자리에 맞게 다시 잘랐습니다.
**새 사진을 추가하실 때도 같은 방식으로 처리해 드릴 테니 원본 그대로 보내주시면 됩니다.**

새 사진을 직접 넣으시려면:

1. 사진 파일 이름을 영어로 바꿉니다. 예: `color-1.jpg`, `perm-1.jpg`
   (한글 파일 이름은 서버에서 깨질 수 있습니다.)
2. `assets/photos/` 폴더에 넣습니다.
3. `index.html` 의 `gallery` 부분을 이렇게 고칩니다.

```js
gallery: [
  { src:"assets/photos/color-1.jpg", alt:{ko:"애쉬 브라운 컬러", en:"Ash brown colour"} },
  { src:"assets/photos/perm-1.jpg",  alt:{ko:"레이어드 펌",     en:"Layered perm"} }
]
```

`src` 를 비워 두면(`src:""`) 사진 대신 자리 표시가 나옵니다. 사진이 준비되기 전까지는 그대로 두셔도 괜찮습니다.

사진은 **한 장에 500KB 이하**로 줄여서 올리세요. 크면 휴대폰에서 느려집니다.
`squoosh.app` 에 사진을 올리면 무료로 줄일 수 있습니다.

## 5. GitHub 에 올리기

**처음 한 번만 하는 준비**

1. github.com 에서 계정을 만듭니다.
2. 오른쪽 위 `+` → `New repository` 를 누릅니다.
3. Repository name 에 `hplace-site` 를 넣고, **Public** 을 고른 뒤 `Create repository` 를 누릅니다.
4. 다음 화면에 나오는 주소를 복사해 둡니다. 예: `https://github.com/내아이디/hplace-site.git`

**파일 올리기 (터미널 없이)**

가장 쉬운 방법입니다. 방금 만든 저장소 화면에서 `uploading an existing file` 링크를 누르고,
`hplace-site` 폴더 안의 파일과 폴더를 통째로 끌어다 놓은 뒤 아래 `Commit changes` 를 누릅니다.

**터미널을 쓰신다면**

```bash
cd hplace-site
git init
git add .
git commit -m "첫 사이트"
git branch -M main
git remote add origin https://github.com/내아이디/hplace-site.git
git push -u origin main
```

## 6. Render 에 배포하기

1. render.com 에 GitHub 계정으로 로그인합니다.
2. 오른쪽 위 `New +` → **`Static Site`** 를 고릅니다. (Web Service 아님)
3. 방금 만든 `hplace-site` 저장소를 고릅니다.
4. 설정을 이렇게 넣습니다.

   | 항목 | 값 |
   |---|---|
   | Name | `hplace` (주소가 됩니다) |
   | Branch | `main` |
   | Build Command | **비워 두세요** |
   | Publish Directory | `.` (점 하나) |

5. `Create Static Site` 를 누르면 1분 안에 배포됩니다.
6. `https://hplace.onrender.com` 같은 주소가 나옵니다.

**이후에 내용을 고칠 때는** `index.html` 을 고쳐서 GitHub 에 올리기만 하면 됩니다.
Render 가 알아서 다시 배포합니다. 따로 누를 버튼이 없습니다.

## 6-1. 배포했는데 화면이 안 보일 때 (순서대로 확인)

에러 메시지 없이 아무것도 안 보인다면 대부분 아래 첫 번째 문제입니다.

### ① 폴더가 한 겹 더 들어간 경우 — 가장 흔합니다

GitHub 저장소 첫 화면을 보세요.

- **`index.html` 이 바로 보이면** 정상입니다. Publish Directory 는 `.` (점 하나)
- **`hplace-site` 라는 폴더만 보이면** 한 겹 더 들어간 것입니다.
  파일을 드래그할 때 폴더째로 올리면 이렇게 됩니다.

폴더가 한 겹 더 들어갔다면 둘 중 하나로 고치시면 됩니다.

**방법 A (더 쉬움)** — Render 설정만 바꾸기
Render → 해당 사이트 → `Settings` → `Build & Deploy` →
**Publish Directory** 를 `.` 에서 `hplace-site` 로 바꾸고 저장 →
오른쪽 위 `Manual Deploy` → `Deploy latest commit`

**방법 B** — GitHub 에서 파일을 바깥으로 꺼내기
`hplace-site` 폴더를 열고 `index.html` 을 클릭 → 연필 아이콘 →
파일 이름 맨 앞의 `hplace-site/` 를 지우고 저장. 나머지 파일도 같은 방식으로.

### ② 브랜치 이름이 다른 경우

Render 설정의 `Branch` 가 `main` 인데 GitHub 저장소가 `master` 이면 아무것도 배포되지 않습니다.
GitHub 저장소 왼쪽 위에 표시된 브랜치 이름과 Render 설정을 같게 맞추세요.

### ③ Static Site 가 아니라 Web Service 로 만든 경우

Render 대시보드에서 사이트 종류를 확인하세요. **Static Site** 여야 합니다.
Web Service 로 만들었다면 삭제하고 `New +` → `Static Site` 로 다시 만드세요.

### ④ 배포가 아직 안 끝났거나 실패한 경우

Render 사이트 화면의 `Events` 탭을 보세요.
`Deploy live` 가 떠야 정상입니다. `Build failed` 면 그 아래 로그를 저에게 보여주세요.

### ⑤ 주소를 잘못 열고 있는 경우

Render 가 준 주소는 `https://` 로 시작합니다. `http://` 로 열면 안 될 수 있습니다.
그리고 브라우저 새로고침은 **Ctrl+Shift+R** (맥은 Cmd+Shift+R) 로 하세요.
그냥 새로고침하면 예전 화면이 그대로 보일 수 있습니다.

### ⑥ 화면이 새까맣기만 하고 글자가 없는 경우

이 버전부터는 `SALON` 설정에 오타가 있어도 글자는 보이도록 만들어 두었습니다.
그래도 비어 보인다면 브라우저에서 **F12 → Console** 탭을 열고,
빨간 글씨가 있으면 그 내용을 저에게 보내주세요.

## 7. 내 도메인 연결하기 (선택)

1. Render 의 사이트 화면에서 `Settings` → `Custom Domains` → `Add Custom Domain`
2. 도메인을 산 곳(가비아, 후이즈 등)의 DNS 설정에 Render 가 알려주는 값을 넣습니다.
3. 몇 분에서 몇 시간 뒤 연결됩니다. HTTPS 는 Render 가 자동으로 붙여 줍니다.

## 8. Supabase 는 언제 필요한가요

지금 사이트는 손님이 **인스타 DM 과 WhatsApp 으로 바로 연락**하는 구조라서 Supabase 가 필요 없습니다.
아래를 하고 싶어지면 그때 붙이시면 됩니다.

- 사이트 안에서 이름·날짜·원하는 스타일을 받아 **저장**하고 싶을 때
- 문의가 몇 건 들어왔는지 **숫자로 보고 싶을** 때
- 시술 기록을 쌓아 **재방문 손님을 알아보고 싶을** 때

말씀해 주시면 문의 폼과 Supabase 연결까지 붙여 드리겠습니다.

## 9. 자주 겪는 문제

| 증상 | 원인과 해결 |
|---|---|
| 글꼴이 다르게 보인다 | `assets/fonts` 폴더가 같이 올라갔는지 확인하세요 |
| 사진이 안 나온다 | 파일 이름의 대소문자까지 정확히 같아야 합니다. `Color-1.JPG` 와 `color-1.jpg` 는 다른 파일입니다 |
| 화면이 하얗게 나온다 | `SALON` 부분에서 쉼표나 따옴표가 빠졌을 가능성이 큽니다. 이 버전부터는 그래도 글자는 보이지만, 메뉴·지점·갤러리가 비게 됩니다. F12 → Console 에서 빨간 글씨를 확인하세요 |
| 배포했는데 주소가 안 열린다 | 6-1 항목을 순서대로 확인하세요. 대부분 Publish Directory 문제입니다 |
| WhatsApp 버튼이 안 열린다 | 번호에 `+`, `-`, 공백이 들어가면 안 됩니다. 숫자만 넣으세요 |
| 인스타 DM 버튼이 안 열린다 | 아이디에 `@` 를 빼고 넣었는지 확인하세요 |
| 지점이 안 보인다 | `branches` 안에서 쉼표가 빠졌거나 마지막에 쉼표가 남아 있을 가능성이 큽니다 |
