# H.PLACE 재고 관리

지점별 미용 재료(염모제·펌제·샴푸·소모품 등)의 입고, 사용, 지점 간 이동을 기록하고
부족한 재고를 한눈에 보는 웹 시스템입니다.
메인 사이트와 마찬가지로 프로그램 설치와 빌드가 필요 없습니다.

## 폴더 구조

```
H_Inventory_Mgmt/
├── index.html   ← 화면 구성
├── styles.css   ← 디자인
├── app.js       ← 기능 (저장 · 계산 · 화면 그리기)
└── README.md    ← 지금 읽고 계신 파일
```

글꼴은 바깥의 `assets/fonts` 폴더를 같이 씁니다. 이 폴더만 따로 떼어 옮기면 기본 글꼴로 보입니다.

## 여는 법

`index.html` 을 더블클릭하면 바로 열립니다.
처음 열면 예시 데이터(5개 지점, 12개 품목, 한 달치 입출고)가 들어 있습니다.
실제로 쓰기 시작할 때는 **설정 → 예시 데이터로 초기화** 대신, 품목과 지점을 직접 고쳐서 쓰시면 됩니다.

## 메뉴별 기능

| 메뉴 | 하는 일 |
|---|---|
| 대시보드 | 재고 금액, 부족 · 품절 건수, 오늘 입고, 이번 달 사용 금액, 최근 기록 |
| 재고 현황 | 지점별 수량과 상태(정상 · 부족 · 품절). 위쪽 ‘지점’을 전체로 두면 모든 지점을 한 표로 비교 |
| 입출고 등록 | 입고 / 출고 · 사용 / 지점 이동 / 실사 조정 |
| 품목 관리 | 품목 추가 · 수정 · 삭제. 최소 재고 아래로 떨어지면 ‘부족’으로 표시 |
| 거래 내역 | 기간 · 유형으로 찾기, 잘못 넣은 기록 취소, 엑셀용 CSV 내보내기 |
| 설정 | 지점 추가 · 이름 변경 · 삭제, 백업 파일 받기 · 복원 |

**실사 조정**은 창고에서 직접 센 수량을 넣으면, 장부와의 차이만큼 자동으로 맞춰 줍니다.

재고 수량은 따로 저장하지 않고 모든 거래 기록을 더해서 계산합니다.
그래서 잘못 넣은 기록은 ‘거래 내역’에서 취소하면 재고도 저절로 바로잡힙니다.

## 꼭 알아두실 점: 데이터 저장 위치

지금 버전은 데이터를 **이 컴퓨터의 이 브라우저 안에만** 저장합니다.

- 다른 컴퓨터나 휴대폰에서 열면 데이터가 따로 보입니다. 지점끼리 공유되지 않습니다.
- 브라우저의 ‘인터넷 기록 삭제’를 하면 데이터가 지워질 수 있습니다.
- 그래서 **설정 → 백업 파일 받기**를 주기적으로 눌러 두세요. 다른 컴퓨터에서는 **복원하기**로 옮길 수 있습니다.

여러 지점이 같은 데이터를 함께 보고, 직원별로 로그인해야 한다면 Supabase 같은 서버 데이터베이스를 붙여야 합니다.
말씀해 주시면 그 단계로 확장해 드리겠습니다.

## 배포 시 주의

메인 사이트를 Render 에 그대로 배포하면 이 시스템도
`https://(사이트 주소)/H_Inventory_Mgmt/` 로 열립니다.
검색엔진에는 나오지 않도록 설정해 두었지만 **로그인 기능은 없습니다**.
다만 데이터는 각자의 브라우저에만 있으므로, 주소를 아는 사람이 열어도 여러분의 재고 데이터는 보이지 않습니다.
